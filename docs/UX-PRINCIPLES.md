# Règles UX — Heritage Guardian

## Condition obligatoire pour toute amélioration future

L'application ne doit pas présenter l'avancement, la qualité ou l'état d'un dossier principalement sous forme de pourcentages, de scores ou de jauges numériques visibles par l'utilisateur.

Les calculs numériques peuvent rester présents dans le domaine technique lorsqu'ils sont réellement utiles au fonctionnement interne, au tri ou à la décision. Ils ne doivent pas devenir le langage principal de l'interface.

### Le langage utilisateur doit être humain et vivant

Une interface doit expliquer :

- ce qui est déjà établi ;
- ce qui mérite encore d'être précisé ;
- ce qui demande une vérification ;
- ce qui bloque réellement le parcours ;
- quelle est la prochaine action utile ;
- pourquoi cette action est pertinente.

Préférer par exemple :

- « Le dossier prend forme »
- « Vous avez déjà réuni plusieurs éléments »
- « Quelques informations restent à préciser »
- « Ce point est prêt à être vérifié »
- « Le parcours continue avec… »
- « Il manque encore un document pour poursuivre »
- « Nous pouvons maintenant examiner la provenance du terrain »

Éviter :

- « 62 % »
- « Score : 74 »
- « Complétude : 80 % »
- « 3/5 étapes »
- « 50 % du parcours »

### Principe de conception

Le système peut calculer un état ; l'interface doit raconter cet état de manière compréhensible et contextualisée.

Chaque indicateur visible doit donc être évalué selon cette question :

> « Est-ce que cette information aide réellement la personne à comprendre sa situation ou à savoir quoi faire ensuite ? »

Si non, elle ne doit pas être affichée.

### Progression

La progression doit être exprimée par des états et des étapes réelles :

- préparation ;
- information réunie ;
- en cours de vérification ;
- point à préciser ;
- parcours bloqué ;
- étape validée ;
- prochaine étape.

Les pourcentages ne doivent pas remplacer cette compréhension.

### Cohérence future

Cette règle s'applique à tous les modules, notamment :

- Accueil visiteur ;
- Accueil connecté ;
- Terrain ;
- Héritage & succession ;
- Conflits ;
- Volontés ;
- Profil ;
- Dossiers ;
- Alertes ;
- Assistant ;
- futurs parcours professionnels.

Toute nouvelle fonctionnalité qui introduit une progression visible doit respecter cette règle dès sa conception.
