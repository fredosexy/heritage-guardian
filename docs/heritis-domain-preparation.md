# Préparation du domaine Heritis

Date : 1 novembre 2026. Aucun achat, raccordement ou changement DNS effectué.

## Adresses candidates, non vérifiées

| Adresse | Usage envisagé |
| --- | --- |
| heritis.app | Nom court pour l’application |
| heritis.africa | Positionnement africain |
| heritis.com | Adresse généraliste |

Ces propositions ne prouvent ni la disponibilité à l’achat, ni le prix, ni un droit sur le nom. La recherche antérieure a signalé des homonymes : vérifier la marque, notamment auprès de l’OAPI, avant achat ou promotion importante.

## Vérifications avant une décision

1. Dans les paramètres du projet, ouvrir Domaines puis Acheter un domaine et rechercher l’adresse, sans finaliser l’achat.
2. Vérifier le prix initial, le renouvellement et les conditions ; l’achat Lovable requiert une offre payante et le rôle propriétaire ou administrateur.
3. Si l’adresse appartient déjà à l’utilisateur, utiliser la connexion de domaine existant seulement après accord explicite.
4. Préserver les enregistrements e-mail existants si des DNS doivent changer.
5. Après accord et configuration, vérifier le domaine puis HTTPS. Ne pas annoncer une adresse comme active avant cette vérification.

L’adresse publiée actuelle reste inchangée. Un domaine de site ne configure pas automatiquement un expéditeur pour les alertes e-mail.
